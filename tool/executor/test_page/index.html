Launch Console

Quick actions for marketing, product, and support teams. Five actions are wired to demo endpoints; one is intentionally broken for QA.

Campaign Stats

Pulls the latest campaign performance metrics and injects them into the status panel.

Sync CRM

Simulates syncing CRM contacts and displays the count of new leads.

Refresh Inventory

Updates the storefront inventory with the latest stock levels.

Send Notification

Triggers a toast indicating a faux notification was sent to subscribers.

Prepare Release

Warms up the release checklist and confirms that QA has been notified.

Book Demo

This action intentionally lacks an event handler. It should highlight missing wiring.
