Audit Checklist Prompt

The executor receives a prompt like the one below. It drives each browser action so the automated audit mirrors what a human reviewer would check.

  1. Open the target page at <URL>.
  2. Hover the primary CTA (#btn1) and capture hover metrics.
  3. Scan every link and record broken responses.
  4. Inspect images and interactive controls for missing labels.
  5. Measure the micro target (.tiny-btn) to confirm touch size.
  6. Detect elements overlapping #btn1.

Why Screenshots Matter

We keep both the before and after states so anyone reviewing the report can see exactly what changed when an action ran. This is critical when the UI shifts during hover or a modal opens unexpectedly.
